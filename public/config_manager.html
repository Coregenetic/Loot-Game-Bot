XP Kurve & Ränge

Wie werden XP berechnet?

1. XP erhalten (Loot-Wert)

Spieler erhalten pro 1.000 Rubel Wert ihres überlebten Loots genau 1 XP (Minimum 10 XP).

Beispiel: 500K Item = 500 XP. 2.5 Mio Item = 2.500 XP.

2. XP pro Level (Anzeige)

Nach jedem Aufstieg beginnt die XP-Anzeige im Chat bei 0. Die Tabelle rechts im "Ränge & XP" Tab zeigt, wie viele XP von 0 an für das nächste Level benötigt werden.

(Im Hintergrund werden die XP als Gesamtsumme gespeichert).

Base XP?
Die Grundmenge an XP für Berechnungen. Standard: 500.
Kurve (Mult)?
Steilheit der XP-Kurve. 1.0 = linear, 1.5 = steil. Standard: 1.5.
Prestige Malus?
Wie viel XP-Abzug (%) gibt es PRO Prestige-Level? 0.10 = 10%.
